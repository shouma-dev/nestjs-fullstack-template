# 选择页面风格

指定了案例名或模板 ID 时，先查[案例索引](references/cases.md)，同名案例按模板 ID 区分。按设计任务选[落地页](../miaoda-landing-page/SKILL.md)、[后台](../miaoda-admin-page/SKILL.md)或[工具](../miaoda-tool-page/SKILL.md)继续实施。已有品牌与用户明确选择优先。

按真实任务选一行，用主背景、文字、强调色的角色和布局原则设计新页面。下表色值是设计起点。应用到固定风格包时通过页面级变量控制品牌区域，按钮、弹层、焦点和状态沿用项目的语义令牌。图像和文案使用项目素材或原创内容。

| 黑金舞台 | 入围展示、抽签、抽奖。黑褐底、暖金高光、高对比大标题，舞台中心预留结果或奖池。配置和历史记录集中在边缘，支持大屏远距识读。 | `#17120E` / `#FFF4DD` / `#E0B566` |
| 极简产品展示 | 新品介绍、设备预约、轻量品牌官网。浅中性底、一张干净的主体图和短标题，规格与卖点用整齐的对齐线组织。提交入口在移动端靠近关键依据。 | `#F6F7F9` / `#19202C` / `#2F59C4` |
| 图像编辑式陈列 | 案例中心、社区相册、实物目录。内容图承担叙事，用统一的图幅和紧凑的图注组织网格，再用一个更大的主图带出重点。无封面时保留可识别的图文结构。 | `#F8F6F0` / `#24201D` / `#7B4830` |
| 模块化资源门户 | 资源导航、企业知识、模板陈列。清晰的筛选和搜索居前，卡片统一呈现标题、归类和入口。首屏放最常用的索引，避免每个模块都争抢主色。 | `#F5F7FA` / `#202B3C` / `#3D51B3` |
| 文档式阅读 | 条款、知识条目、评分记录。稳定行宽、短节标题和标签，目录或筛选围绕正文布置。关键结论、来源和更新信息紧贴对应段落。 | `#FBFAF6` / `#24282E` / `#3A5770` |
| 高对比实验 | 创意工作室、主题展览、叙事海报。大字、几何边界或强色块挑一个当主角，说明和按钮保持稳定位置。关掉装饰动效后仍能找到入口。 | `#141414` / `#F5F4EF` / `#BBF451` |

## 互动与 AI 工具

| 风格 | 适用场景和设计做法 | 底色／主文字／强调 |
| --- | --- | --- |
| 彩色插画互动 | 教育、人格互动、轻量游戏。用自制插画和清晰色块传递反馈，一屏聚焦一个行动，分数、状态和答案用文字或符号补充颜色。 | `#FFF5E8` / `#252548` / `#6846B8` |
| 国风节庆 | 新年活动、贺卡、节日互动。朱红、米白和暖金可用于边框与背景，留出独立的结果或祝福区。使用原创插画和短流程，弱化密集纹样对阅读的干扰。 | `#FFF3DC` / `#4F211A` / `#A52926` |
| 桌面棋盘与卡牌 | 棋盘、抽签卡、一步步揭晓的玩法。让棋盘或卡牌占最大面积，规则、当前回合和重开分布在边缘。窄屏将状态与控件放在棋盘之外。 | `#F0E1C4` / `#34241A` / `#745034` |
| 柔和留白 | 探索、反馈、感谢信、低压力入口。奶白底配淡绿或浅紫，标题和一个清晰动作置前。浅色承担分组与情绪，文字仍使用深色。 | `#F4F8F3` / `#25382C` / `#397254` |
| 单任务工具 | 短文本转换、计算、翻译。一个输入区、一个主行动和同屏结果，空间优先留给输入和输出。历史、说明和进阶选项可用次级入口。 | `#FAFAFC` / `#222332` / `#6247B9` |
| 双栏创作工具 | 合同审阅、内容改写、图文生成。桌面两列分配输入与结果，结果区显示版本和处理状态。移动端顺序呈现，方便返回修改且保留输入。 | `#F6F7FB` / `#202738` / `#385CC0` |
| 暗色创作控制台 | 提词、分镜、开发或媒体工具。炭灰层级、低饱和分隔线和一处明亮行动色，编辑面、预览、进度和工具栏各有固定位置。 | `#171A22` / `#EBEEF8` / `#90A7FF` |
| 移动拟物工具 | 习惯记录、快速计时、短频操作。突出一个大读数或当前状态，用手感明确的大按钮、轻质感和简短底部导航表达主要操作。 | `#152723` / `#F6F0D8` / `#9CD5AB` |
| 三维工作台 | 空间导览、CAD、设备分解或地图。最大区域留给可操作场景，树、属性、定位和复位围绕主视口。加载和无法运行三维时提供可读的列表或静态图。 | `#F1F4F6` / `#223140` / `#3E687D` |

## 业务与数据

| 风格 | 适用场景和设计做法 | 底色／主文字／强调 |
| --- | --- | --- |
| 冷色运营台 | 库存、工单、审批与资产。白底、灰蓝分隔、深色或浅色导航，工具栏放搜索筛选和批量动作，表格强调对齐、可扫读状态与明细入口。 | `#F4F6FA` / `#1B2736` / `#305CAC` |
| 植物绿运营台 | 质检、门店运营、流程跟进。灰绿或米白为表面，深绿强调当前视图与主要操作，异常仍使用有文字标识的告警色。适合长时间操作和少量摘要。 | `#F3F6EE` / `#233429` / `#345F48` |
| 暖纸经营台 | 零售、成本、采购、餐饮。暖白配陶土或深棕，保留纸面式分组和横向对齐。用小面积强调色指示金额、状态或提示，表头保持易扫读。 | `#FAF5EC` / `#30261F` / `#8A4A30` |
| 色带业务门户 | 服务台、项目入口、运营首页。顶部色带突出当前计划、关键数值或任务，下面承接摘要、待办和明细。只使用一个主色带，并让到期与待处理状态显式可见。 | `#F6F5F9` / `#241F33` / `#654594` |
| 看板与排程 | 待办、班表、营销日历。将阶段、日期或资源做成稳定的列，卡片显示任务标题、状态和时间。窄屏可切换列表，避免只能拖拽的操作。 | `#F5F7FB` / `#1F2937` / `#3C56B1` |
| 亮色分析仪表盘 | 营销归因、库存、财务。时间范围和筛选靠近标题，指标行后接趋势、构成与明细。维持图表的色义和时间范围，区分缺数、零值和异常。 | `#F7F8FC` / `#242C3B` / `#324EB2` |
| 夜间分析仪表盘 | 直播运营、监控、风控。深色图层上使用少量高亮系列和显式基线，优先让关键告警或趋势可识别。附上数值、标签与列表以便精确查看。 | `#121827` / `#EDF3FF` / `#71B8FF` |
| 集中表单 | 报名、预约、反馈、线索与申请。用居中窄栏或清晰分组安排必填、帮助和校验。输入较长时保持逐步进度可见，错误提示贴近字段并保留已填内容。 | `#F9F8FC` / `#27243A` / `#5845A1` |
