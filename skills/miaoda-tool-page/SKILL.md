# 工具与创作工作台生成

确定用户带来什么、要产出什么、是否需要反复比较修改。首屏呈现正在处理的对象和可以开始的动作。

| 任务 | 页面结构 | 反馈 |
| --- | --- | --- |
| 参数换算 | 类别较多时侧边选材料或形状；主区只出现当前类型的尺寸、单位、数量和计算结果。移动端用选择器代替常驻类别树。 | 数值用等宽数字，结果旁放单位与计算依据。缺参数、零和负值分别处理，单位切换同步换算。 |
| 原文审阅与改写 | 桌面原文和结果并列，结果项可定位原段，再调整或重新处理。窄屏按“输入／结果”切换并保留草稿。 | 新请求处理中标明状态并保留可读的上一版；区分示例、旧结果与本次结果。错误允许修订并重试。 |
| 绘画与分镜 | 连续创作以画布或分镜序列为中心，工具靠近对象，属性放在侧栏。多阶段制作从项目进入当前阶段，保留回看素材的入口。 | 当前工具、选区、撤销和保存结果可见；窄屏把属性折叠到面板，留下可实际操作的主区域。 |
| 轻量互动 | 短时打卡、计时或测验将主要读数与一个可触达的动作放在一起。按产品性格选用拟物、柔和或插画。 | 进入、进行、结束或中断后返回均有明确路径，图案与音效辅以文字状态。 |

例如合同审阅可在左列放合同和立场，右列放带原文定位的风险项；型材计算可把形状选择、尺寸输入和结果放在同一阅读路径。用当前需求的对象、数据和文案重新设计。

验证一次从空输入到完成的操作，再修改输入、触发错误、返回结果。复制或导出应取当前可见版本，未配置的 AI 能力呈现可理解的状态。选择表现语言时查[风格目录](../miaoda-case-styles/SKILL.md)中的单任务、双栏创作、暗色控制台或移动拟物。
