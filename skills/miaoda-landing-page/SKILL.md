# 落地页生成

先从需求找出访客、要了解的对象、做决定前缺的证据和主行动。例如“陶艺工作室开放日”需要作品近景、时间地点、场次和预约，“设备采购”需要型号差异、规格和询价。把这些信息直接画进页面。

先确定访客值得停下来看的一件东西，再写标题。印刷课可以直接叫“鸢尾套印开放日”，在画面旁让人切换两块色版；预约设备体验可以让人查看对应型号的细节。把品牌和品类换成另一个行业读一遍，仍然成立的宣传句通常可以删掉。图片有具体作者或来源时，把图注放在图边。

| 访客为什么来 | 首屏构图 | 下一屏到主行动 |
| --- | --- | --- |
| 了解一件产品 | 能靠外形判断的产品让主图占首屏；靠精度、兼容性或使用条件做决定的产品先呈现比较依据。把查看细节或体验的入口放在证据附近。 | 用功能近景说明差异，重要规格成行对照，预约区给出地点与可选时段。 |
| 报名活动 | 海报式主视觉带日期、地点和报名入口。如果时间和人数是决定因素，把这两项放到按钮旁。 | 按时间排议程，讲者与对应场次关联，表单逐项校验，成功页显示已选场次。 |
| 看展或逛品牌空间 | 可用高反差大字配单幅作品，或暖纸色配宽幅摄影。给作品完整边界或有意的出血裁切。 | 展项用图注讲清材质、作者或空间特点，行程信息与预约相邻。空间本身是卖点时加入位置、平面图或交通说明。 |
| 浏览作品或案例 | 一件重点作品加清晰图注，后接可筛选的图像目录。项目很多时把分类入口提到首屏。 | 打开条目后呈现问题、过程和结果，再返回原筛选位置。无实际指标时使用作品、流程或细节作证。 |
| 认识创意团队 | 大字和强色块围绕团队的真实作品组织视觉。一个显著的方向性元素已能带动视线。 | 从重点作品进入项目细节，再到团队与联系。持续动效提供静态或减少动态的呈现。 |

**落到组件。** 按内容拆成首屏、可验证的证据区、完成行动的区域。两段之间改变阅读方式，例如从大图切到紧凑规格行。图片用项目可用的素材，先确定主体与裁切焦点；缺图可用真实产品界面、结构图、字体与留白建立重心。按钮文字应预告实际结果，如“查看可预约时段”。

**尺寸起点。** 桌面正文列约 30–40 个汉字宽，主标题可从 `clamp(2.25rem, 5vw, 5rem)` 起调。窄屏按内容重排标题、关键证据和主行动，改变图片裁切位置。预约表单较长时首屏可只留入口，点击后直接到表单或预约路由。

**交付检查。** 在宽屏和 390px 窄屏看首屏、读第二段、完成主行动，再用键盘重走一次。确认长标题、图片慢加载、已满场次、提交失败与成功回执符合本次需求。没有业务数据或提交能力时清楚标示实际状态。实现采用项目已有控件与页面级样式。

可在 [风格目录](../miaoda-case-styles/SKILL.md) 选择电影感发布、极简产品、图像编辑、黑金舞台等不同表现。

[鸢尾套印开放日](references/print-open-day.html) 可离线切换朱红、靛蓝和合印效果，并下载所选场次的日历提醒。页面为本项目设计，练习图取自葛饰北斋的公版木版画，经数码分色重新配色。[馆藏原作](https://www.metmuseum.org/art/collection/search/37192)
